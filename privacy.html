Privacy policy

Deep Night Tales Motor · Last updated: 13 November 2026

Who uses this tool

Deep Night Tales Motor is a private tool used only by the owner of the YouTube channel Deep Night Tales, on the owner's own computer. It has no other users and no public sign-in.

What it accesses

With the owner's consent, the tool uses two read-only Google permissions:

  • YouTube Data API (read-only): the list of the channel's own uploads, with their titles, status and publication dates.
  • YouTube Analytics API (read-only): the channel's own statistics, such as views, watch time and traffic sources.

The tool cannot upload, edit or delete videos, comments or any other content.

How the data is used

The data is used only to schedule the channel's own videos and to write statistics reports for the channel owner.

Where the data is stored

The access token is stored in the operating system's keychain on the owner's computer. Reports are saved as files on that same computer. No data is sent to any server operated by this tool, because there is none.

Sharing

The data is not sold, not used for advertising and not shared with third parties. It is not transferred to anyone except as needed to provide the features described above, to comply with applicable law, or for security purposes.

Google API Services User Data Policy

The use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Removing access

The owner can revoke the tool's access at any time from the Google Account permissions page, at myaccount.google.com/permissions. Deleting the stored token removes all access.

Contact

Questions about this policy can be sent through the About section of the Deep Night Tales channel on YouTube.
